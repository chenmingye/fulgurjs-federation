## 三、本次真正修复的插件缺陷及发布

### 3.1 类型降级只警告却不生成声明（5.0.3）

5.0.2 在远程 `devFsRoot:false` 或 fsRoot 本机不可读时声称“降级为 any”，实际没有输出远程模块声明。有效 tsconfig 的真实消费者因此 TS2307，不能当成正常降级。

`packages/plugin/src/dts.ts` 新增 `writeAnyModules`：按 manifest 的公开 exposes 生成简写环境模块声明，兼容默认、具名及副作用导入；跳过内部 setup；覆盖过期源码映射；没有公开模块时删除陈旧声明。新增真实 TypeScript 编译验证和不可读路径覆盖回归。5.0.3 提交 `a43c99d47da581e2c96f15835ff0d95ba9b4812a`，正式 tag/Release/npm 已发布。

### 3.2 合法相对开发地址无法生成类型（5.0.4）

MES 宿主合法使用 `//localhost:4529/flowable`，页面运行正常，但类型生成器直接 `new URL(devEntry)`，导致获取 manifest 失败、无直连声明。这是插件 URL 解析不一致，不能让使用者改写所有配置回避。

`fetchManifest(devEntry, origin)` 改用 `new URL(devEntry, origin)`，origin 依次取 Vite 显式 server.origin、resolvedUrls.local、实际协议和端口。真实 HTTP 服务回归覆盖协议相对地址及同源相对地址。README 同步类型降级语义并纠正过期质量门禁数字。MES 真实配置保留协议相对地址，自动生成 BPM 19 条和 lowcode 6 条公开模块声明。

## 十、懒加载与网络字节（真正量化）

路由/页面表声明本身不下载页面。第一次进入某业务页只加载该 expose 及其依赖；setup 是初始化模块，不等于所有页面。访问过的模块由浏览器和运行时缓存复用。显式 `preloadRemote` 会主动下载整远程，故只在冷加载测量完成后执行。

本节请求字节只统计 flowable/lowcode 两个远程 base 下的网络流量；dashboard 的0请求指远程请求，不是整站没有下载宿主壳或宿主依赖。显式 preload 测量调用的是当前 runtime 实例的 preloadRemote，作为测试探针，不是建议应用通过内部 window 全局作为日常接入 API。

统计使用 Chrome CDP `Network.loadingFinished.encodedDataLength`，缓存命中传输 0；不能把 responseReceived 的头部字节当下载量。业务 expose 按 manifest 文件路径去重，setup、入口、manifest、CSS、字体、文档单独分类。dependencyScript 含页面依赖及共享实现，没有产物图证明时不全部称为 shared。
