## 9. 覆盖缺口与方法说明（如实声明）

- `runtimeChunk` / `devSharedSelf` / `devCorsOrigins` / `devFsRoot` / `runtimePlugins` / `eager` 的覆盖形态是**插件自动化测试**（真实构建/dev server/类型生成断言），不是浏览器演示——构建期选项没有可观看的 UI 语义，测试文件见 §1 对应行。
- Vue 与 React 同名 API（remoteComponent/defineBridgeApp/createHostPages 等）为两套独立实现，分别核销（§2.4 vs §3），差异点（useLoadRemote hook 形态 / ErrorBoundary 组件形态）仅在 /react 存在。
- 单例/实例身份证据口径：对象/函数**严格相等**（卡① atom 工厂、卡⑫ getLoadedShare/pin）、**模块求值次数恒 1**（卡①）、跨端状态传播（卡① 三方同 atom）——不使用相同字符串、Symbol 描述或人为 globalThis 标志充当证据。
