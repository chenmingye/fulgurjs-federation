## 四、与原版的已知同款差异（非联邦回归，实测对照记录）

| 现象 | 定性 | 证据 |
|------|------|------|
| AMIS 卡片发起页表单区空白 | 原版设计：原版 Detail/Master 均无 AMIS 表单渲染分支，AMIS 发起走 AMIS 站点/业务页 | 原版源码 diff + 基线实测 |
| 模块设计页字典/列表接口报错（res.map 等） | 原版同款：axios 拦截器不解包 jeecg result，页面形状错配（已在本仓修为守卫） | 8661 基线实测同报错 |
| `/tab/page` 404 | demo boot 未部署低码模块服务；垫片返回诚实空列表 | 基线 404 同款 |
| 修改态流程标识/名称 disabled | 原版设计（BasicInfo `:disabled="!!modelData.id"`） | 源码对照 |
| bpm 确认按钮显示 i18n 键名（common.ok） | 子应用 locale 装载缺口，原版乾坤同样存在；功能不受影响 | 基线截图同款 |
