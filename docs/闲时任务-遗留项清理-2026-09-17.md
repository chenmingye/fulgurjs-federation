### A.【第一优先】06 流程详情 AMIS 表单区回落 iframe 通道（回归）

**现象**：dev+prod 的 06 详情 iframe=1（其余 25 页 0）。iframe src=
`{origin}/main/AmisFormRouterPage?name=&formId=2099454871698411522&loadingRaise=1`
——走了乾坤时代的 iframe 旧通道，而非联邦直渲染。AMIS 表单字段在 iframe 内渲染
（amis 验证脚本 hasFields=false 待查）。

**已排查事实**（勿重复）：
- detail 源码 `demo-bpm/src/views/bpm/processInstance/detail/index.vue`：
  setup 处 `const isFederatedRealm = !!(window as any).mainAppProps`；AMIS 分支
  isFederatedRealm=true 时走 `federatedAmisParams + loadFederatedForm(true)`（模板
  `<component :is="FederatedAmisForm">`），false 时才写 `AmisFormComponentUrl`（iframe src）
- 诊断时点 mainAppProps=true、__FULGUR_HOST_APP__=true（桥已跑），但 iframe 已渲染
  → **疑似 setup 捕获 isFederatedRealm 的时序早于 fulgurBridge()（mainAppProps 写入）**；
  桥的调用点有两处：admin `staticRouter.ts` 路由组件 loader 与
  `LayoutContent（layouts/default/content/index.vue）fulgurComp computed`——双通道并存，
  触发顺序需实测确认
- 本轮重建新增：staticRouter 直挂 27 页路由（component=fulgurPageComponent）+ LayoutContent
  联邦分支——两通道都通向同一 detail 组件，但 AMIS 分支的分支判定只算一次（setup 期）

**修法方向（按推荐序）**：
1. 把 `isFederatedRealm` 从一次性常量改为函数/响应式读取，或在 AMIS/CUSTOM 分支内
   实时判 `!!window.mainAppProps`（最小改动）；
2. 或统一触发时序：LayoutContent 在 setup 同步期（渲染前）就调 fulgurBridge()（挪出
   computed），保证子组件 setup 前桥已写入；
3. 修完验收：dev+prod 06 详情 iframe=0、AMIS 表单标题+字段渲染、零 pageerror
   （复验命令 `cd e2e && NO_PROXY=... VTAG=dev|prod VBASE=... node amis-dev-verify.mjs`，
   断言 iframeCount=0 且 hasTitle/hasFields=true）。

## 4. 工具与坑（上一轮实测沉淀，务必遵守）

1. **长链 cd 命令在上下文压力下会损坏**（几十条 cd 粘连成一条）——一律用
   `find /Users/Admin/Desktop -maxdepth N -name X` 定位路径 + 短命令；
2. Write/路径手打易错（杂物 误写为 权物/权/权限）——写完用 ls 核对；
3. `configureServer` 返回值必须是**函数**（post 中间件，无参、闭包用 server），
   返回对象会 `fn is not a function` 崩；
4. ESM 里没有 `__dirname`——execSync 用 `cwd: process.cwd()`；
5. heredoc 里的 `${...}` 会被 zsh 展开——写含模板字符串的文件用 `<<'EOF'`（带引号）；
6. tsup --clean 会清掉 dist/runtime.js（gen-runtime 消费后）——需要独立 runtime 产物时
   手动重跑 esbuild 命令再拷贝；
7. admin 编辑源码后 vite 有 **重编译窗口**（页面卡 CSSC 加载动画 30-60s）——探针前先
   确认编译完成，勿把窗口期状态当回归；
8. dev server 常驻进程持旧模块——改 vite 配置/优化配置后必须重启；
9. 并发跑构建 + 浏览器套件会互相干扰（evaluate 被导航打断）——**串行执行**；
10. matrix/collect 的「OK」只代表脚本跑完——套件断言要在各自输出里核对；
11. `pnpm install` 在根目录可能因 "Already up to date" 跳过 install 钩子——进各子应用
    显式 install；
12. 测试数据：AMIS 待办实例（"AMIS联邦验证2"）可能被 flow/amis 套件消费——没了就重跑
    `e2e/amis-seed3.mjs`（记录输出的 modelKey）+ `e2e/amis-start.mjs <modelKey>` 再造。
