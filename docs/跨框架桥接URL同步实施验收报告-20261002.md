## 0. 原型门禁（§1，先证明后冻结）

27/27 PASS（`evidence/proto-gate-final.txt`，驱动 `proto-gate.mjs`）：两种组合（Vue 宿主×React 子、React 宿主×Vue 子）+ hash 变体——首次详情深链、子应用 Link/RouterLink push（历史恰 +1、root 不重挂）、宿主同前缀菜单、后退/前进、**真实取消**（Vue 守卫拒绝 / RR7 canNavigate+useBlocker 双源）、根重定向 replace（全新页面历史恰 2）、挂载 pending 时换路径（最新目标、不闪默认页）、卸载后迟到导航失效（cancelled、URL 不变）、全程零 pageerror/console.error。

**原型实证并冻结进任务书的四条结论**（§1 更新）：①VR4 `app.use(router)` install 初始导航竞态——初始 push 落定前不得 install/mount；②RR7 navigate 被 blocker 拦截时**静默返回 void**（dist 源码核实）→ 端口 canNavigate 同谓词预判；③子应用受控路由 = VR4 createRouter(memory)/RR createMemoryRouter；④挂载 pending 期换路径必须 mount 前重读宿主最新位置（Vue 异步续体需 alive 标志）。

## 6. 实际支持范围与尚存限制

**支持**：Vue 3 宿主（VR4 history/hash）× React 18/19 子；React 宿主（RR data router browser/hash）× Vue 3 子；path/search/hash、push/replace、深链/刷新/收藏、宿主菜单、前进后退、真实守卫取消（Vue）/blocker+预判取消（RR）、KeepAlive 暂停、会话换代、子目录部署（basename/routerBase 分层）。

**限制（如实声明）**：React 宿主仅 data router（declarative 不支持取消）；React Router ≥6.11；无 SSR/RSC、跨窗口、嵌套多级桥接路由代理、TanStack 等其他路由库（可经 BridgeHostNavigation/BridgeChildRoute 端口扩展）；workspace link 开发态的 pnpm 双仓库 RR 副本需 resolve.alias 统一（正式包消费无此问题）；URL 只恢复路由位置，不持久化表单/滚动/业务数据。
